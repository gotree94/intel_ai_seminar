## 2. 세미나의 목적 (추론)

1. **Intel 중심 AI 생태계 확산**: 서버, 스토리지, 메모리, 로봇, 금융, 의료 파트너가 함께 "Intel 위에서 AI가 실제로 돌아간다"를 보여주는 행사.
2. **GPU 중심 구도에 대한 대안 제시**: 학습용 고성능 GPU 경쟁이 아니라 **추론과 에이전트 운영의 비용·효율**로 승부.
3. **Physical AI(로봇·엣지) 선점**: 엣지 SoC(CPU+GPU+NPU)와 Physical AI Studio를 개발 플랫폼으로 내세워 로봇 개발자를 Intel 생태계로 유입.
4. **소버린 AI 수요 공략**: 데이터를 외부로 내보내지 않고 자체 인프라에서 AI를 운영하려는 국내 기업·기관 대상.

> **한 줄 요약**: GPU 한 종류에 의존하지 않고, CPU·대용량 메모리·NPU·특화 칩을 조합한 Intel 플랫폼으로 데이터센터부터 엣지, 로봇까지 AI를 구현한다.

## 3. 핵심 축 ① GPU 중심 구도의 대안

**전략**: 학습용 GPU 경쟁이 아니라 추론·에이전트 운영의 비용과 효율로 승부.

- **CPU(Xeon 6) + 대용량 메모리**: Xeon 서버(KTNF, 정원엔시스/HPE, ASUS, Supermicro, Acer/Altos), CXL 메모리 확장(Panmnesia), 고밀도 스토리지(Seagate MOZAIC+)
- **이기종 조합**: CPU에 SambaNova 같은 가속기를 붙여 에이전틱 AI 추론
- **GPU 병행**: NH농협은행 사례처럼 B70급 GPU를 추론용으로 쓰는 사례도 있어 "필요한 곳에 맞는 칩"이라는 메시지로 읽힘

→ 상세: `01_gpu_alternative_xeon_memory.md`

## 4. 핵심 축 ② Physical AI 선점

**전략**: 엣지 SoC(CPU+GPU+NPU 통합)와 Physical AI Studio를 개발 플랫폼으로 내세워 로봇 업체가 Intel 위에서 개발하도록 유도. 핸즈온이 별도 방(101)으로 배정된 것도 이 때문으로 보임.

- Intel Core Ultra Series 3(Panther Lake)급 엣지 프로세서
- Physical AI Studio: 데이터 수집, 모델 미세조정, 최적화·양자화, 배포 지원
- OpenVINO Physical AI: 학습된 정책(VLA)을 실제 로봇에 배포하는 런타임 프레임워크

→ 상세: `02_physical_ai_studio.md`
